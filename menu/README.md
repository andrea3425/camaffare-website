# Foto dei prodotti

Metti qui dentro le foto dei piatti del menu.

## Regole

- **Nome file** = campo `foto` della voce in `js/menu-data.js`
  (es. `menu/arancino-ragu.jpg` → `foto: 'menu/arancino-ragu.jpg'`).
  Tutto minuscolo, parole separate da trattino, niente spazi né accenti.
- **Formato**: quadrato (1:1), consigliato **800×800 px**, JPG.
- **Peso**: max ~200 KB a foto, altrimenti la pagina si appesantisce.
- **Inquadratura**: piatto centrato, sfondo pulito, luce naturale.
  Le card ritagliano al centro, quindi lascia un po' d'aria attorno.

## Se una foto manca

Non succede niente: la card mostra un placeholder colorato con l'icona
della categoria e la scritta "foto in arrivo". Appena carichi il file con
il nome giusto, la foto compare da sola — non serve modificare il codice.
